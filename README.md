# CodeBurger · 麦门人格汉堡工厂

**Feed Your Agent.**

答 5 道生活小题，组装出一只只属于你的汉堡人格，再把它喂给你的 Agent。

> 2026 麦当劳 1024 程序员创意开发大赛（M-Code）参赛作品。
> 项目由参赛者独立开发，**非麦当劳官方产品**。

---

## 它是干嘛的

不是一个点餐助手。

CodeBurger 把「汉堡」当成一种人格容器：你回答 5 道题，它把你映射到 8 种汉堡人格中的一只，
当场把这只汉堡组装出来，然后你可以把它喂给页面里的 Agent —— Agent 会因此进入专注、灵感、Bug 或摸鱼四种状态之一。

全程不需要登录，不填手机号，答案不上传。

## 五个步骤

| 屏幕 | 发生什么 |
| --- | --- |
| 1 · 人格测试 | 5 道生活情境题，每题 4 个选项，约 40 秒 |
| 2 · 生成结果 | 组装出你的汉堡，摊开它的面包 / 夹层 / 装饰 / 服装 / 表情五轴 |
| 3 · 投喂 | 把汉堡喂给 Agent，看它进入什么状态、说什么话 |
| 4 · 分享卡 | 导出 3:4 的 PNG，直接发朋友圈 |

## 8 种汉堡人格

8 只全部是汉堡形态，靠**面包 / 夹层 / 装饰 / 服装 / 表情**五个轴区分。

| 角色 | 性格 | 一句话 |
| --- | --- | --- |
| 社牛辣椒堡 | 外向、热情、能量拉满 | 我认识的人比你刷的视频还多。 |
| 深夜摸鱼堡 | 白天关机、夜里才活过来 | 别问我白天在干嘛，我没醒。 |
| 灵感芝士堡 | 好奇心重、点子跳脱 | 刚又想出三个主意，一个都没记住。 |
| 淡定双层堡 | 稳、慢、不慌 | 急也没用，反正都要排队。 |
| 计划鸡腿堡 | 有条理、目标感强 | 我的待办事项有编号，还有优先级。 |
| 冒险鳕鱼堡 | 敢试、不怕翻车 | 没吃过的东西才值得点。 |
| 手抖薯饼堡 | 冲动、手快、小错不断 | 我不是故意的，但确实掉了。 |
| 佛系蔬菜堡 | 不争不抢、养生、慢慢来 | 都行，都可以，看你。 |

角色资产见 `docs/art/`，设定表见 `docs/art/八格设定表.png`。

## 人格是怎么算出来的

**确定性映射，不是随机抽。**

1. 五道题各覆盖一个维度，选项权重只有 −1 / 0 / +1 → 得到一个五维向量
2. 对 8 个原型向量算加权欧氏距离，取最近的一个；并列时按 id 字典序
3. 同样的答案永远得到同一个人格，不随刷新变化

枚举全部 1024 种答题组合，每一种都有确定归属，且只落在这 8 个人格内。见 `tests/persona.test.mjs`。

**人格测试是趣味娱乐内容，不具备心理测量学效度，不构成任何专业建议。**

## 真实 MCP 集成

项目接入了麦当劳官方 MCP 服务（`https://mcp.mcd.cn`），做了 35 个工具的能力核查与真实调用验证。
完整取证过程、条款原文引用、判定结论都在 [`docs/GATE_A_EVIDENCE.md`](docs/GATE_A_EVIDENCE.md)。

**架构上有一条硬红线：公开页面零 MCP 调用。**

```
公开 H5（谁都能玩）                    WorkBuddy Skill（本地 · 真实 MCP）
  · 零 MCP 调用                          · 用使用者自己的凭证
  · 零官方数据集                          · 由使用者本人在对话里触发
  · 原创虚拟配料 + 趣味映射                ← 这一层才算「个人正常使用场景」
```

这么做是因为《麦当劳MCP服务规则》第三条2 写着「不支持任何形式的批量、高频或自动化调用」，
第六条2 把「利用脚本、爬虫或任何自动化工具调用本服务」列为禁止行为。
网页代所有访客调用，无论用谁的 Token，都在禁止范围内。

**官方营养数据的公开使用范围尚未获得授权，因此本项目不分发任何官方数据集。**
页面上的「真实餐品参考」层默认关闭。

## 三层数据结构（真实与虚构严格分开）

| 层 | 内容 | 标注 |
| --- | --- | --- |
| L1 官方真实餐品参考 | 默认关闭，需授权后开启 | `reference` |
| L2 趣味人格映射 | 人格 → 餐品**类别**的趣味对应 | `非科学结论` |
| L3 原创虚拟配料 | 全部原创命名，不承载任何官方营养数值 | `virtual` |

**不把整款真实餐品的营养数据解释为某个虚拟配料的属性。** 这两层在 UI 上是分开的两张卡。

## 技术

单 Vite + TypeScript 应用，零运行时依赖（除构建期）。

- 人格引擎：确定性五维映射，纯函数
- 角色渲染：SVG（骨架）+ 位图（正式资产）
- 分享卡：原生 Canvas 2D，不引第三方库
- 存储：localStorage，不上传

```bash
npm install            # Windows 沙箱环境问题见 docs/SETUP_WINDOWS.md
npm run dev            # 本地开发，端口 5180
npm run build          # 产出纯静态 dist/
npm test               # 19 条单元测试
npm run gate:a         # 重跑 MCP 合规取证（需要自己的 Token）
npm run mockups        # 生成设计稿
npm run brief          # 从 personas.ts 生成角色美术需求表
```
